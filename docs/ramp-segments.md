# 경사로 시작·끝과 휠체어 속도 (분석 도구)

11/05 면담 질문: **경사로의 시작과 끝을 어떻게 정하고, 휠체어 속도는 어떻게 채울 것인가.**
`app/analysis/ramp_segments.py`, `scripts/ramp_segments.py`로 답한다. 경로 계산과는 별개로 주행 기록을
일괄 분석하는 도구이고, 결과는 L3 간선 상태(경사 구간 분할)의 입력 후보다.

```bash
python -m scripts.ramp_segments --input observations_2026-11-20.csv \
    --out-dir output/ramps/2026-11-20 --plot
```

## 방법

| 단계 | 내용 | 기본값 |
|---|---|---|
| 편향 | 평지가 대부분이므로 중앙값 ±2%p 안만 남겨 중앙값을 다시 구한다. `g = slope − 편향` | `--bias`로 지정 가능 |
| 핵심 구간 | `abs(g) ≥ 3%`에서 시작, `abs(g) ≥ 1.5%`인 동안 유지(히스테리시스). 3창(6초) 미만은 버리고, 1창 끊김은 잇는다 | `--on`, `--off`, `--min-windows` |
| 시작·끝 경계 | 변화율 `dg/dt`(%/s)가 가장 큰 곳. 2초 창 평균은 계단 모양 경사를 기울어진 선으로 뭉개는데, 그 선의 가운데(변화율 최대 = 고원값의 절반)가 실제 경계다. 반값을 지나는 시각을 선형 보간해 2초보다 촘촘하게 잡는다 | 앞뒤 3창 탐색 |
| 변화 시작·끝 | 경계에서 바깥쪽으로 가며 변화율이 최대값의 20% 아래로 떨어지는 시각 | `--onset-frac` |
| 길이·속도 | GPS를 시간으로 보간, 5창 이동 평균 후 누적 거리. 경계 사이 거리 = 길이, 길이/시간 = 속도 | |
| 걸러내기 | 평균 속도 0.3 m/s 미만(정지 중 흔들림) 제외. 경계 사이에 GPS가 없으면 길이·속도 비움 | |
| 같은 장소 | 경사로 중간 지점이 25 m 안이면 같은 경사로 (오르내림 왕복 확인) | |

**전이 구간을 채우는 법.** 변화 시작~경계, 경계~변화 끝은 `onset`/`settle`로 표시한다. 대표 경사(핵심 구간
중앙값)에는 넣지 않고, 간선 경사 프로필을 채울 때는 이 구간을 평지와 고원값 사이 직선으로 잇는다.

**합성 검증 (tests/test_ramp_segments.py).** 2초 창 평균과 잡음 0.3%p를 넣은 합성 기록에서 경계를
창 위치와 상관없이 1초 안(잡음 없으면 0.6초 안), 경사는 ±0.4%p, 길이는 ±3 m로 찾는다.

## 결과

| 기록 | 편향 | 찾은 구간 | 경사 | 길이 | 속도 중앙값 |
|---|---|---|---|---|---|
| 11/19 루프 (보행) | −0.02% | 2 (+GPS 없는 짧은 구간 1) | +6.5%, −5.8% | 46.5 m, 48.3 m | 평지 1.44 m/s |
| 11/20 경사로 (휠체어) | +2.37% | 10개, 장소 9곳(1곳 왕복) | 오르막 +5.4~+5.9%, 내리막 −4.3~−9.8% | 25~67 m | 평지 1.15 · 오르막 1.17 · 내리막 1.13 m/s |

- 11/19 값은 앞서 손으로 구한 값(R1 +6.5% 약 47 m, R2 −5.8% 약 48 m)과 같다.
- 11/20 왕복한 경사로(#7 내리막 −6.0%, #8 오르막 +5.7%)는 0.3%p 차이로 일치하고, 높이 차도 −2.72 m / +2.84 m로 맞는다.
- 변화 시작~경계 중앙값 2.9초, 경계~변화 끝 3.4초. 1.15 m/s에서 약 3~4 m가 전이 구간이다.
- 휠체어 속도는 경사 5~6%에서 평지와 거의 같았다(1.15 vs 1.17 m/s). 이동 시간 계산의 시작값으로 쓰고,
  사용자 기록이 쌓이면 개인 속도로 바꾼다.

## 한계

- 편향은 기록 하나에서 상수로 본다. 장착 자세가 바뀌면 기록을 나눠 돌린다.
- GPS 오차(수 m)가 길이에 그대로 들어간다. 경사로 길이의 정답은 현장 실측으로 맞춰야 한다.
- 지도에 표시한 경사로 번호와의 대응은 아직 손으로 맞춘다.
